# Sai Abhinav Pattoor — Portfolio

Static portfolio for new-grad Data Engineer and Software Engineer roles.

## Hosting

GitHub Pages: `spattoor/spattoor.github.io`, `main`, repository root.
Public URL: https://spattoor.github.io/

## Files

- `index.html`, `style.css`, `app.js`: the complete portfolio.
- `404.html`: custom GitHub Pages not-found page.
- `resume.pdf`: supplied final resume, with Sai's later ProcureX bullet added.
- `assets/skyline.jpg`, `assets/sai-abhinav.jpg`: compressed versions of the existing assets.

The skyline design, portrait, colors, and typography are retained. No build step
or runtime dependencies are needed. The decorative Three.js scene is no longer
loaded. Fonts use Google Fonts with system fallbacks and `display=swap`.
