# Sai Abhinav Pattoor — Portfolio

Static portfolio for software engineering and data analytics opportunities.

## Publish

Repository: `spattoor/spattoor.github.io`. Enable GitHub Pages from `main`, root directory. The public URL is `https://spattoor.github.io/` once deployment succeeds.

## Preview

Run `python3 -m http.server 4173` in this directory, then open http://localhost:4173.

## Assets

The portrait is supplied by Sai. The skyline was generated for this portfolio. Three.js is bundled locally with its license in `vendor/THREE-LICENSE.txt`.
